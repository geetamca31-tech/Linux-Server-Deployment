# Linux Server Deployment – Module 02

## Project Overview
This project demonstrates practical knowledge of Linux, Networking and Cloud Infrastructure as part of Module 02 at Codomax Digital.

## Objectives
- Learn Linux CLI commands.
- Understand file management and permissions.
- Perform user and group management.
- Understand process and service management.
- Configure SSH keys.
- Learn IP addressing and DNS.
- Understand networking ports and firewalls.
- Deploy a Linux web server.

## Technologies Used
- Linux / Ubuntu
- Killercoda Online Linux Playground
- Bash Commands
- SSH
- Networking
- Nginx

## Practical Implementation
1. Linux user creation and management.
2. File and directory operations.
3. File permissions.
4. Group management.
5. Process management.
6. Networking configuration.
7. SSH key generation.
8. Firewall configuration.
9. Nginx web server deployment.
